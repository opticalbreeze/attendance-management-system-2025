# Archive フォルダ

このフォルダには、過去のバックアップファイルや使用済みの検証ファイルが格納されています。

## フォルダ構成

### 📁 old_backups/
古いデータベースバックアップファイル

- `backup_20260114_133532.db` - 2026/01/14 13:35のバックアップ
- `backup_20260114_133931.db` - 2026/01/14 13:39のバックアップ

## 保管方針

### バックアップファイル
- 1ヶ月以上経過したバックアップファイルは定期的にアーカイブ
- 重要なマイルストーン（大規模な修正前後）のバックアップは長期保存

### 検証ファイル
- 目的を果たした一時的な検証ファイルをアーカイブ
- 再利用可能なものは utilities フォルダへ移動

## 注意事項
- アーカイブファイルの削除は慎重に行ってください
- バックアップファイルは定期的に整理し、ディスク容量を管理してください

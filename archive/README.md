# アーカイブディレクトリ

このディレクトリには、一時的な検証ファイルや削除リスクがあるファイルを保管しています。

## 📁 ディレクトリ構成

### `verification/` - 検証ファイル

一時的な検証・修正スクリプトを保管しています。これらのファイルは、特定の問題解決やデータ修正のために作成されたものです。

**注意**: これらのファイルを実行する前に、必ずバックアップを取得してください。

#### ファイル一覧

- **`check_*.py`**: データ検証スクリプト
- **`fix_*.py`**: データ修正スクリプト
- **`test_*.py`**: テストスクリプト
- **`matsuura_*.py`**: 特定の従業員データ修正スクリプト
- **`*.sql`**: SQL修正スクリプト
- **`*.backup`**: バックアップファイル

### `old_backups/` - 古いバックアップ

古いデータベースバックアップファイルを保管しています。

**注意**: これらのファイルは、データベースの復旧に使用できますが、古いバックアップは削除しても問題ありません。

---

## ⚠️ 削除について

これらのファイルは、将来的に削除を検討できますが、以下の点に注意してください：

1. **検証ファイル**: 特定の問題解決のために作成されたものなので、同様の問題が発生した場合に参考になる可能性があります。
2. **バックアップファイル**: データベースの復旧に使用できるため、十分な期間が経過するまで保持することを推奨します。

削除する場合は、以下の手順を推奨します：

1. ファイルの内容を確認
2. 不要であることを確認
3. バックアップを取得（念のため）
4. 削除実行

# AIへのオーダーガイド

## 目的
このドキュメントは、AIに正確で効率的なオーダーを行うためのガイドラインです。
特に、5000（運用）と5001（開発）コンテナの差異調査など、複雑な調査タスクで使用します。

---

## 重要な原則

### 1. 調査範囲を明確に指定する

**❌ 悪い例：**
```
「5000と5001コンテナのコードの差異を分析して」
```
→ AIがAPIコード（Python）のみを確認し、フロントエンドコードを見落とす可能性がある

**✅ 良い例：**
```
「5000と5001コンテナのコード（APIとフロントエンド含む）の差異を細かく分析して」
```
または
```
「5000と5001コンテナでマウントされているすべてのファイルの差異を確認して」
```

### 2. 特定の機能や画面を指定する

**✅ 良い例：**
```
「search画面の時間外申告機能について、5000と5001の実装差異を調査して」
```
```
「お知らせ画面からsearch画面への遷移時の通信エラーについて、5000と5001の実装を比較して」
```

### 3. 調査の深さを指定する

**✅ 良い例：**
```
「5000と5001のdocker-compose設定と、マウントされているすべてのファイルを比較して、差異をリストアップして」
```
```
「search画面のJavaScriptコードについて、templates/search.htmlとtemplates_dev/search.htmlの機能差異を詳細に比較して」
```

## オーダー例

### パターン1: コンテナ間の差異調査

```
5000（運用）と5001（開発）コンテナの以下の差異を詳細に調査して：

1. docker-compose.ymlとdocker-compose.dev.ymlの設定差異
2. マウントされているすべてのファイルの差異
   - APIコード（Python）
   - フロントエンドコード（HTML/JavaScript）
   - 設定ファイル
3. 環境変数の差異
4. 特定の機能（例：search画面の時間外申告機能）の実装差異

結果は表形式で整理して、影響範囲も記載して。
```

### パターン2: 機能の実装確認

```
search画面の[機能名]について：
1. templates/search.htmlとtemplates_dev/search.htmlの実装を比較
2. 必要なJavaScript関数が存在するか確認
3. APIエンドポイントの呼び出し方法を確認
4. 5000と5001で動作が異なる場合、原因を特定

コードの差分を具体的に示して。
```

### パターン3: エラー調査

```
[エラー内容]について：
1. 5000と5001の両方で発生するか確認
2. サーバーログとブラウザコンソールの両方を確認
3. 関連するコードファイルを特定
4. 実装差異がある場合は、どちらが正しい実装か判断

調査結果と修正案を提示して。
```

## AIに確認すべきポイント

### 調査前に確認
- [ ] 調査範囲は明確か？（APIのみ？フロントエンドも含む？）
- [ ] 対象コンテナは指定されているか？（5000？5001？両方？）
- [ ] 特定の機能や画面が指定されているか？

### 調査結果の確認
- [ ] docker-compose設定の差異を確認したか？
- [ ] マウントされているすべてのファイルを確認したか？
- [ ] フロントエンドコード（HTML/JavaScript）も確認したか？
- [ ] 環境変数の差異も確認したか？

## よくある問題と対策

### 問題1: AIがAPIコードのみを確認する

**対策：**
```
「APIコードとフロントエンドコード（HTML/JavaScript）の両方を比較して」
```

### 問題2: AIが「差異なし」と断言する

**対策：**
```
「docker-compose設定を確認して、マウントされているファイルをすべて比較して。
差異がない場合は、その根拠を明確に示して。」
```

### 問題3: AIが調査を省略する

**対策：**
```
「コードを変更する前に、まず詳細な調査を行って。
調査結果を報告してから、修正案を提示して。」
```

## 今回の事例から学んだこと

### 問題の経緯
1. 「5000と5001コンテナのAPIコードの差異を細かく分析して」と依頼
2. AIがPythonのAPIコードのみを確認
3. 「差異なし」と断言
4. 実際には`templates/search.html`と`templates_dev/search.html`に大きな差異があった

### 正しいオーダー例
```
5000（運用）と5001（開発）コンテナについて：
1. docker-compose.ymlとdocker-compose.dev.ymlの設定を比較
2. マウントされているすべてのファイル（APIコード、フロントエンドコード含む）の差異を確認
3. search画面の時間外申告機能の実装差異を特に詳細に調査

結果は表形式で整理して、影響範囲も記載して。
```

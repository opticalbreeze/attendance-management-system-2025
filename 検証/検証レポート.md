### 1. 出勤打刻忘れを退勤打刻忘れを時刻で認識しているか

**検証結果**: ⚠️ **部分的に問題あり**

**現状**:
- `attendance_check_service.py`の`check_time_difference_errors`関数で、打刻1回のみの場合に「出勤打刻漏れ」または「退勤打刻漏れ」を判定している
- しかし、Excel出力（`monthly_report.py`）では、打刻があればその時刻を表示してしまう

**問題点**:
- 出勤打刻漏れの場合でも、退勤打刻があればその時刻が出勤列に表示される可能性がある
- 退勤打刻漏れの場合でも、出勤打刻があればその時刻が退勤列に表示される可能性がある

**検出された問題**:
- 行22（堀江　敦）: 出勤打刻漏れなのに出勤時刻が入力されている

**推奨修正**:
- Excel出力時に、エラーメッセージに「出勤打刻漏れ」が含まれている場合は出勤列を`'-'`に設定
- エラーメッセージに「退勤打刻漏れ」が含まれている場合は退勤列を`'-'`に設定

### 3. 退勤打刻忘れ・出勤時刻忘れ・どちらもない打刻もない打刻忘れは打刻漏れとして認識してエクセル出力できているか

**現状**:

**問題点**:

- 同じ日の同じエラータイプは1件としてカウントする

## 実施した修正

### 修正1: 打刻漏れ時の時刻表示の改善

**修正ファイル**: `monthly_report.py`

**修正内容**:
- エラーメッセージから「出勤打刻漏れ」「退勤打刻漏れ」「打刻漏れ」「打刻なし」を判定
- 出勤打刻漏れの場合は出勤列を`'-'`に設定
- 退勤打刻漏れの場合は退勤列を`'-'`に設定
- 「明」勤務の場合も同様に処理

**修正コード**:
```python
# エラーメッセージから打刻漏れを判定
has_clock_in_leak = any('出勤打刻漏れ' in alert.get('message', '') for alert in alerts)
has_clock_out_leak = any('退勤打刻漏れ' in alert.get('message', '') for alert in alerts)
has_missing_punch = any('打刻漏れ' in alert.get('message', '') or '打刻なし' in alert.get('message', '') for alert in alerts)

# 打刻漏れの場合は該当する列を'-'に設定
if has_clock_in_leak or (has_missing_punch and not clock_times):
    cell5 = ws.cell(row=row, column=5, value='-')
else:
    cell5 = ws.cell(row=row, column=5, value=clock_times[0] if clock_times else '-')

if has_clock_out_leak or (has_missing_punch and len(clock_times) <= 1):
    cell6 = ws.cell(row=row, column=6, value='-')
else:
    cell6 = ws.cell(row=row, column=6, value=clock_times[-1] if len(clock_times) > 1 else '-')
```

**問題**:
- 24勤で出勤時刻を2回打刻した場合、2回目の打刻が退勤時刻として扱われる可能性がある

**対応方針**:

### 課題3: 24勤での打刻漏れの表示

**問題**:
- 24勤で出勤時刻も退勤時刻も打刻漏れの場合、当日と「明」勤務の日の両方に「打刻漏れ」を表示したい

**対応方針**:
- `attendance_check_service.py`の`check_off_day_shift_attendance`関数を修正
- 前日の24勤で打刻漏れの場合、「明」勤務の日にも「打刻漏れ」を表示するロジックを追加
